# Dev Log - 2026-08-14

## 變更內容

### system.pkg_repos：第三方 dnf repo 管理

新增 `system.pkg_repos`，讓套件安裝前可以先宣告需要的 dnf repo。單一 struct 涵蓋兩種情境：只給 `id`（+`enabled`）代表既有 repo 只需翻轉開關；給 `baseurl`（+選填 `gpgkey`）代表 repo 檔不存在、需要建立並匯入 key。

- `EnsurePkgRepos`（`internal/ops/pkg.go`）
- 調整既有 repo 的 enabled 狀態時，直接改寫 `.repo` 檔的 `enabled=` 那行，不呼叫 `dnf config-manager --set-enabled/--set-disabled`——dnf5 的 config-manager plugin 不吃這組 dnf4 語法

### Schema 改名：packages → pkgs，dnf_repos → pkg_repos

為了讓 `pkg_repos` 跟 `pkgs` 兩個關鍵字對稱、好記，把既有的 `system.packages` 一併改名。

### system.skip_update / EnsureSystemUpdate

Block III 第一件事改成先 `dnf update -y --refresh` 把系統套件更新到最新，`system.skip_update: true` 可跳過。dnf 本身對已是最新的系統就回報無事可做，沒有另外寫 check 步驟。

### system.tmpfiles / EnsureTmpfiles

新增 `system.tmpfiles`，宣告開機時要清除的路徑（例如上次非正常關機留下的 app lock 檔），寫進 `/etc/tmpfiles.d/trisolaran.conf`。不需要自訂 systemd unit，因為 `systemd-tmpfiles-setup.service` 本來就內建、每次開機都會執行。

### userspace.pipeline 取代 userspace.scripts

原本 `userspace.scripts` 固定排在 Block IV 最後（artifact 還原、repo clone 之後），但像 oh-my-zsh 的安裝程式會無條件覆蓋 `.zshrc`，排在還原之後就會把剛還原回去的內容蓋掉。

`userspace.pipeline` 把 Block IV 改成一串有序 step，每個 step 是 `script`（一行 shell）或 `run`（`dehydration`/`repos`，觸發 artifact 還原或 repo clone）。預設（沒有 step 明確寫 `run: dehydration`/`run: repos`）維持原本行為：還原跟 clone 自動排在所有 script 之前。明確寫出來則照宣告順序執行，可以把安裝腳本插在還原之前。

### Blueprint 嚴格欄位驗證

`ParseBlueprint` 改用 `yaml.v3` 的 `KnownFields(true)`，未知欄位直接報錯，不再被靜默忽略。避免 schema 改名（例如 `packages` → `pkgs`）後，舊設定檔裡的欄位悄悄失效卻沒有任何錯誤訊息。

### Dehydration：缺檔案不再中止整個打包

`tri dehydra` 打包時，宣告的路徑如果不存在，過去會直接報錯中止。改成：

- 路徑完全不存在 → 區分「只是最後一段（leaf）不存在」還是「中間某層資料夾就斷了」，兩種訊息不同
- 路徑存在但是空目錄、或空檔案（0 bytes）→ 照常打包，但也標記出來
- 以上四種情況都只是 warning，不會讓整個 `tri dehydra` 失敗

### 執行報告改成寫檔案

`tri dehydra`／`tri rehydra` 如果有值得注意的項目（上述缺檔案情況、下面的還原衝突），不再把整份清單直接印到終端機洗版，而是寫成報告檔（`<artifact>.notices.txt` / `rehydra-notices.txt`），CLI 上只留一行摘要 + 檔案路徑。沒有任何項目就不產生檔案。

### 時間同步 + 還原衝突處理（newer wins）

`tri rehydra` 的 Block III 新增 `EnsureTimeSync`：呼叫 `timedatectl set-ntp true`，並在時限內輪詢確認同步成功（非同步失敗不中止，只記錄成功與否）。

`artifact.Restore` 現在會比較每個檔案的還原版本跟磁碟上現有版本：

- 時間同步成功：比較修改時間，較新的贏（磁碟較新就保留磁碟版本，不覆蓋）
- 時間同步失敗：無法信任時間比較，一律保留磁碟版本
- 磁碟上原本沒有這個檔案：正常還原，不算衝突

保留磁碟版本的情況一律記錄進上面的報告檔，不會讓整個還原中止。

### Home 目錄權限收緊

`EnsureUserHome` 新建/修正 home 目錄權限從 `0755` 改成 `0700`，避免其他本機使用者能讀進去。冪等檢查也從「至少 0755」的 bitmask 改成嚴格相等，否則已經是 0755 的目錄永遠不會被收緊回 0700。

### 建置旗標

`Taskfile.yml` 的 `build` 加上 `-ldflags="-s -w"` 縮小體積；新增 `build-debug` task，用 `-gcflags="all=-N -l"` 關閉最佳化/inlining，方便用 debugger 單步除錯。
